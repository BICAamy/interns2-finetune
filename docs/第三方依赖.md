### 运行时约束

- 固定提交的自动安装逻辑要求 CPython 3.10；虽然 `setup.py` 声明 `python_requires >= 3.9`，其 SOFA 下载和配置代码会明确拒绝非 Python 3.10 环境。
- 官方 Linux 预编译包为 SOFA `v24.06.00`，目标 CPU 架构为 `x86_64`。
- 上游安装脚本会下载并解压 SOFA，还会在 Python 环境中创建 SOFA 相关链接，因此不应在宿主机或 InternS2/LMDeploy 服务容器内直接执行。
- Step 4 将在独立仿真镜像中安装并验证 SOFA、`sofa_env` 和图形渲染依赖，避免影响现有 GPU 模型服务。
- `SKIP_SOFA=1 pip install -e .` 只适用于容器内已经正确安装了兼容 SOFA 的情况，不应将它当作跳过 SOFA 依赖的普通安装开关。

### 克隆与服务器更新

首次克隆主项目时使用普通 Git 命令：

```bash
git clone <MAIN_REPOSITORY_URL> interns2-finetune
```

服务器已经克隆了主项目时，只需要更新主仓库：

```bash
cd /home/xl/interns2-finetune
git pull
```

`third_party/sofa_env` 是主仓库的普通目录，不需要也不应执行 `git submodule` 命令。

### 上游升级规则

不自动跟随 `main` 分支。需要升级时，先在独立临时目录克隆上游仓库，检查上游变更、SOFA/Python 版本、授权协议和 API 兼容性，再用新的上游跟踪文件替换此快照。不得复制上游 `.git` 目录。升级后必须重跑仿真镜像构建、上游示例和本项目契约测试，并同步修改本文档的固定提交与运行时约束。

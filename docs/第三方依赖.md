### 运行时约束

- 固定提交的自动安装逻辑要求 CPython 3.10；虽然 `setup.py` 声明 `python_requires >= 3.9`，其 SOFA 下载和配置代码会明确拒绝非 Python 3.10 环境。
- 官方 Linux 预编译包为 SOFA `v24.06.00`，目标 CPU 架构为 `x86_64`。
- 上游安装脚本会下载并解压 SOFA，还会在 Python 环境中创建 SOFA 相关链接，因此不应在宿主机或 InternS2/LMDeploy 服务容器内直接执行。
- Step 4 将在独立仿真镜像中安装并验证 SOFA、`sofa_env` 和图形渲染依赖，避免影响现有 GPU 模型服务。
- `SKIP_SOFA=1 pip install -e .` 只适用于容器内已经正确安装了兼容 SOFA 的情况，不应将它当作跳过 SOFA 依赖的普通安装开关。

### 克隆与服务器更新

首次克隆主项目时使用普通 Git 命令：

```bash
git clone <MAIN_REPOSITORY_URL> interns2-finetune
```

服务器已经克隆了主项目时，只需要更新主仓库：

```bash
cd /home/xl/interns2-finetune
git pull
```

`third_party/sofa_env` 是主仓库的普通目录，不需要也不应执行 `git submodule` 命令。

test -f third_party/sofa_env/setup.py
test -f third_party/sofa_env/LICENSE

固定的上游提交是 `85bf7e05dd088b824794dda0046679df13b13e6e`。由于快照内不再包含独立 Git 仓库，版本以本文档记录和引入快照的主仓库提交为准。

### 上游升级规则

不自动跟随 `main` 分支。需要升级时，先在独立临时目录克隆上游仓库，检查上游变更、SOFA/Python 版本、授权协议和 API 兼容性，再用新的上游跟踪文件替换此快照。不得复制上游 `.git` 目录。升级后必须重跑仿真镜像构建、上游示例和本项目契约测试，并同步修改本文档的固定提交与运行时约束。

## 华沿 E05 机器人模型

- 上游项目：[`huayan-robotics/elfin_model`](https://github.com/huayan-robotics/elfin_model)；
- 固定提交：`84baf18d37eefa46b6f092c7fa1f105f81f70ecb`；
- 使用路径：`model/485/elfin5` 和 `urdf/ROS2/485/elfin5.urdf.xacro`；
- 引入方式：由于实验室服务器无外网，已将上述路径的最小只读快照放在 `third_party/elfin_model/`，随主项目传输，不包含上游 `.git` 和无关型号；
- 完整性：`simulation/scripts/verify_e05_model.sh` 校验所用 STL/xacro 的逐文件 SHA256，来源提交记录在快照 README 中；
- 授权说明：该固定提交未提供独立 LICENSE 文件；当前快照只用于本项目内部、设备配套的离线实验。公开仓库、镜像或商业分发前必须向华沿确认模型文件的再分发授权；
- 本地修正：六轴关节原点和轴保持厂家新版 E05 xacro；普通版 J6 到末端的 `146 mm` 按 E05-Pro 力控尺寸图修正为 J6 到法兰 `184 mm`；普通版第六连杆网格仅按 `184/146` 沿局部 Z 缩放作为力控末端可视化代理。

E05-Pro STEP、通信协议和 Python Library 资料由设备厂家提供，保存在项目的 `hua_yan_robo/` 资料目录中。运行时代码不解析长篇 PDF，也不调用真实机械臂；`CPS.py` 中已经确认存在关节/TCP读取、正逆解、TCP标定、直线运动和力控接口，留待后续实机适配阶段按安全流程接入。

## Step 5 离线 Python wheelhouse

实验室服务器无外网，`third_party/wheelhouse/` 保存
`simulation/step5-requirements.txt` 的 Linux x86_64、CPython 3.10 固定 wheel。
`docker/simulation/Dockerfile.offline` 在安装前校验 `SHA256SUMS`，并以
`--no-index` 安装。该目录只补充已验证 Step 4 镜像中不存在的 Step 5 依赖，
不重复保存 SOFA、Open3D 等大体积依赖。

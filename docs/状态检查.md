## 检查整体状态
若使用 api 方式启动：
```bash
export INTERNS2_INFERENCE_MODE=api
./scripts/services/status.sh
```
若使用 local 方式启动：
```bash
export INTERNS2_INFERENCE_MODE=local
./scripts/services/status.sh
```
## 健康检查
```bash
./scripts/services/health_check.sh
```
## 查看监听窗口
```bash
ss -ltnp | grep -E ':(23333|8000|8001|8002|8003)\b'
```
端口对应：
- 23333：模型服务
- 8000：agent-web
- 8001：robot-runtime
- 8002：planner-adapter
- 8003：真实模式下的仿真回退服务

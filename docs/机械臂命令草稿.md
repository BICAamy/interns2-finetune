# 1. 启动服务器

模型加载方式和网页版本可以独立选择。网页版本支持：

- `web`：只开放演示版（默认）。
- `web_inside`：只开放内部版。
- `both`：同时开放演示版和内部版；两者共用同一个后端和机器人控制会话，不会抢占端口或重复向机械臂发命令。

使用已经部署的 API，并只启动演示版网页：

```bash
export INTERNS2_INFERENCE_MODE=api
export INTERNS2_WEB_VARIANT=web
./scripts/services/start_all.sh
```

使用已经部署的 API，并只启动内部版网页：

```bash
export INTERNS2_INFERENCE_MODE=api
export INTERNS2_WEB_VARIANT=web_inside
./scripts/services/start_all.sh
```

使用已经部署的 API，同时开放两个网页：

```bash
export INTERNS2_INFERENCE_MODE=api
export INTERNS2_WEB_VARIANT=both
./scripts/services/start_all.sh
```

使用本项目原来的本地模型时，只需替换模型加载方式；网页选择保持不变：

```bash
export INTERNS2_INFERENCE_MODE=local
export INTERNS2_WEB_VARIANT=both
./scripts/services/start_all.sh
```

API 模式默认使用：

- 地址：`http://127.0.0.1:23333/v1`
- 模型：`interns2-medlora`
- 密钥文件：`configs/interns2-api-key.local`

## 2. 停止服务器

```bash
./scripts/services/stop_all.sh
```

API 模式只停止本项目的网页、规划器和机器人服务，不停止外部模型服务；本地模式会把
由 `start_all.sh` 启动的 LMDeploy 模型服务一起停止。

## 3. 建立主机与服务器隧道
```bash
# 将mac端口18001映射到服务器（5090）的端口18011上
# 18000：网页
# 18001：Mac 网关连接服务器 robot-runtime
ssh -N \
  -o ExitOnForwardFailure=yes \
  -L 18000:127.0.0.1:8000 \
  -L 18001:127.0.0.1:8001 \
  5090
```

# 4. 启动网关
```bash
# 启动网关: 建立主机与机械臂的连接
./scripts/edge/start_gateway.sh 
```

# 访问网页
```bash
# INTERNS2_WEB_VARIANT=web：演示版
http://127.0.0.1:18000/

# INTERNS2_WEB_VARIANT=web_inside：内部版
http://127.0.0.1:18000/

# INTERNS2_WEB_VARIANT=both：同时开放
http://127.0.0.1:18000/         # 演示版
http://127.0.0.1:18000/inside/ # 内部版
```

`both` 模式仍然只需要一条 `18000 -> 8000` 的网页隧道。不要重复运行两次
`start_all.sh`；两个页面共享 `/api`、`/ws`、数字孪生画面和同一套真机安全状态。

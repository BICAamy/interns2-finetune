# 1. 启动服务器
```bash
./scripts/services/start_all.sh
```

## 2. 建立主机与服务器隧道
```bash
# 将mac端口18001映射到服务器（5090）的端口18011上
# 18000：网页
# 18001：Mac 网关连接服务器 robot-runtime
ssh -N \
  -o ExitOnForwardFailure=yes \
  -L 18000:127.0.0.1:8000 \
  -L 18001:127.0.0.1:8001 \
  5090
```

# 3. 启动网关
```bash
# 启动网关: 建立主机与机械臂的连接
./scripts/edge/start_gateway.sh 
```

# 访问网页
```bash
http://127.0.0.1:18000
```
